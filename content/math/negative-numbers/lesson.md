# Negative Numbers

When a problem has a negative number in it follow these rules:

1. A positive number added by a negative number will subtract the negative number against the positive.

Examples: 5 + -3 = 2, 10 + -11 = -1

2. A negative number added by another negative number will add to each other to make a bigger negative number.

Examples: -5 + -3 = -8, -10 + -11 = -21
